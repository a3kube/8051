The 8051 simulator being used is EdSIM51 
4 7-Segment display are used with common Anode.
  All 4 Anodes are shorted and connected to Logic 1.
  If Logic O is provided to Cathod point of a segment, that segment will glow. 

The Port P3 is used to select one of the 7-segment display. with the help of 2 to 4 MUX.
